## 🏛️ The Stack

These aren't separate projects. They're organs of the same system.

⚡ **OLYMPUS** — Governance-native AI infrastructure. Self-hosted on a Dell R740 (472 GB RAM, 51 TB storage). 26 containers. Fail-closed by design — every decision logged, every mutation gated, every service accountable. The constraints are the architecture.

🧠 **STYX** — State-first context engine (patent pending). Compresses meaning instead of storing raw conversation. Benchmarked against RAG and GraphRAG with [published methodology](https://github.com/MatoTeziTanka/styx-results) — results speak for themselves. The algorithm is protected; the evidence is public.

🎖️ **VALOR** — AI-assisted veteran claims platform, built at OSDRI. This is where the stack meets real people. Evidence gathering, statement drafting, intake automation, eFolder analysis. Real cases, real outcomes, daily caseload.

🌱 **Sprout** — A systems programming language. Growing runtime, grammar, and toolchain. Where this goes next isn't public yet.

📈 **KERDOS** — Algorithmic trading infrastructure. Dedicated execution plane in C#/.NET 8. Safety-first paper trading with multi-check preflight.

🏟️ **Agora** — Community companion for [OpenAI's Parameter Golf](https://github.com/MatoTeziTanka/parameter-golf). Live leaderboard with code-based technique classification — inspects actual submissions, not PR descriptions.

## 🧭 How I Think

- 💬 **Plain language over jargon.** If I can't explain it simply, I don't understand it yet.
- 🔬 **First principles over convention.** If the answer is "that's how everyone does it," I ask why.
- 🏗️ **Governance is the foundation.** Not a layer added later. The system should explain itself at any point.
- ✅ **Verify before claiming.** Every assertion should carry evidence.
